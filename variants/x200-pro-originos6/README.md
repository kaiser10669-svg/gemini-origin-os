# Gemini by kaiser — X200 Pro / OriginOS 6

Отдельная версия **v3.1-x200pro-originos6** для Vivo X200 Pro с OriginOS 6. Доработки вызова на экране блокировки и автоозвучки проверены владельцем на этом телефоне. Модель и версия OriginOS указаны со слов владельца.

Исходная версия v3.0 проверялась на **X500 Ultra / OriginOS 7** по информации владельца. Её исходники `app/`, установщик `installer/Install_Gemini.bat` и оба APK v3.0 сохранены без изменений. Эта папка содержит независимую копию приложения: сборка и установка v3.0 не используют её файлы.

| Версия | Устройство / прошивка | Установщик |
|---|---|---|
| Исходная v3.0 | X500 Ultra / OriginOS 7 | [`../../installer/Install_Gemini.bat`](../../installer/Install_Gemini.bat) |
| Отдельная v3.1 | X200 Pro / OriginOS 6 | [`Install_Gemini_X200_Pro_OriginOS6.bat`](Install_Gemini_X200_Pro_OriginOS6.bat) |

На X500 Ultra новая версия не проверялась. Используйте для него исходную v3.0. После обновлений Google или OriginOS вызов и автоозвучку следует проверить повторно: они зависят от системных разрешений и интерфейса Google.

## Что изменено

- Вызов Google проходит через `TriggerActivity`, которая может отображаться поверх экрана блокировки
- `vivo_jovi_power_wakeup_switch` записывается в `system` с отдельным разрешением `WRITE_SETTINGS`
- Добавлены переходы к разрешениям OriginOS для Google и утилиты: показ на экране блокировки, окна из фона, автозапуск
- Jovi переводится в режим без озвучки ответов (`secure setting_voice_mode=2`), сохраняя голосовое пробуждение
- Автоозвучка различает «Слушать» и «Приостановить», чтобы не останавливать уже начавшийся ответ; неудачное нажатие можно повторить в пределах текущего ожидания
- Диагностика показывает этап вызова и состояние кнопки озвучки без текста запросов и ответов

## Установка на X200 Pro / OriginOS 6

Готовый комплект без исходников: [отдельная папка релиза](../../release-x200-pro-originos6/README.md) или [ZIP с APK, установщиком и ADB](../../Gemini_X200_Pro_OriginOS6_v3.1.zip). Распакуйте ZIP целиком и следуйте инструкции внутри.

1. Скачайте репозиторий целиком, сохранив структуру папок. ADB берётся из исходной папки `installer/platform-tools/`. Для отдельного комплекта можно скопировать эту папку `platform-tools` рядом с новым скриптом
2. Включите отладку по USB, подключите только один телефон, подтвердите разрешение отладки и оставьте экран разблокированным. Используйте основной профиль Android, user 0
3. Запустите [`Install_Gemini_X200_Pro_OriginOS6.bat`](Install_Gemini_X200_Pro_OriginOS6.bat). Скрипт выведет модель и сборку телефона. Подтвердите `Y`, только если устанавливаете на X200 Pro / OriginOS 6: профиль выбирается вручную
4. Скрипт устанавливает только [`Gemini_X200_Pro_OriginOS6_v3.1.apk`](Gemini_X200_Pro_OriginOS6_v3.1.apk), выдаёт разрешения и открывает утилиту. Он останавливается при ошибке и не удаляет приложения автоматически; уже выполненные команды не откатываются
5. В Gemini откройте **Профиль → Настройки → Управление устройствами → Gemini на заблокированном экране** и разрешите использование без разблокировки
6. В утилите откройте **OriginOS: Google на экране блокировки** и включите **Display on lock screen**. Через соседнюю кнопку разрешите это же для самой утилиты, а также **Background pop-ups** и **Autostart**
7. Если служба специальных возможностей выключена, разрешите ограниченные настройки в информации о приложении и включите службу **Gemini & Circle to Search — X200 Pro / OS 6**
8. Отдельно включите **Hi, Jovi** в настройках голосового пробуждения

Доступ к звонкам и сообщениям без разблокировки настраивается отдельно в Gemini. Двойной тап по крышке зависит от поддержки жеста прошивкой; этот сценарий здесь не проверялся.

После запуска или перезапуска сервера ADB установщик проверяет подключение до 10 раз с паузами примерно по секунде. Это даёт серверу время обнаружить телефон. Если устройство не появилось или отладка не разрешена, установка не начинается. Экран должен оставаться разблокированным до завершения установки APK: при блокировке OriginOS может вернуть `INSTALL_FAILED_ABORTED: User rejected permissions`.

## Подпись APK и возврат к исходной версии

Пакет сохранён прежним: `com.kaiserdev.geminitrigger`. Две версии одновременно установить нельзя. Новый APK подписан отдельным ключом, поэтому Android не принимает его как обновление исходной v3.0 с другой подписью. При такой ошибке новый установщик остановится. Для перехода удалите прежнюю утилиту вручную, затем запустите нужный установщик. При удалении теряются настройки и разрешения утилиты; Google и Gemini не удаляются.

Для возврата удалите вариант X200 Pro, установите исходный [`Gemini_by_kaiser_v3.0.apk`](../../releases/Gemini_by_kaiser_v3.0.apk) и запустите исходный установщик. Повторно проверьте службу специальных возможностей и настройки ассистента. Удаление приложения само по себе не возвращает системные настройки.

Чтобы вернуть озвучку Jovi, выберите **BlueAI → BlueLM Copilot → Announcement mode → Automatic announcement** (`secure setting_voice_mode=0`). При необходимости восстановите прежние назначения кнопки питания и ассистента через настройки телефона. Возвращайте настройки после удаления варианта X200 Pro, иначе он применит свой профиль снова при запуске.

## Сборка из исходников

Скрипт собирает только `app/` из этой папки и пишет результат в её `build/`. Исходные файлы, установщик и APK v3.0 он не перезаписывает.

Нужны Windows PowerShell, Android SDK Platform 34, Build Tools 36.0.0, JDK с поддержкой `--release 8` и собственный ключ подписи. Пароль ключа передайте через переменную окружения `GEMINI_KEYSTORE_PASSWORD`. Ключи и пароли в репозиторий не добавляются.

Из этой папки:

```powershell
.\build.ps1 -AndroidJar C:\Android\Sdk\platforms\android-34\android.jar `
    -BuildTools C:\Android\Sdk\build-tools\36.0.0 `
    -KeyStore C:\Keys\gemini-local.p12 -KeyAlias gemini-local `
    -JavaBin 'C:\Program Files\Java\jdk-25\bin'
```

Результат: `build/Gemini_X200_Pro_OriginOS6_v3.1.apk`. Для установки своей сборки замените только одноимённый APK в этой папке. Для последующих обновлений сохраняйте один ключ подписи.

Диагностика:

```powershell
adb shell dumpsys activity service com.kaiserdev.geminitrigger/.GeminiPowerService
```

## Проверка на устройстве

Владелец подтвердил на X200 Pro / OriginOS 6:

- Вызов Gemini удержанием кнопки питания при заблокированном телефоне
- Вызов фразой **Hi, Jovi** при заблокированном телефоне
- Отсутствие параллельного голосового ответа Jovi
- Озвучку ответа Gemini без ручного нажатия «Слушать»

Эти сценарии проверялись на сборке с теми же доработками. При подготовке отдельной версии изменены название приложения и обозначение версии; после этого APK пересобран. Итоговый APK установлен через отдельный `.bat` на том же телефоне. Исходная v3.0 на X500 Ultra в рамках этой доработки повторно не проверялась.

## Проверка установщика без телефона

```powershell
.\checks\Check-Installer.ps1
```

Проверка исполняет копии настоящего `.bat` с подменами ADB и выбора пользователя во временной папке. Телефон и настоящий сервер ADB не используются. Нужен Windows PowerShell 5.1 с компилятором `Add-Type`.

Проверяются 13 сценариев: установка с ADB из репозитория и рядом со скриптом, восстановление подключения после первого отказа, отмена, отсутствие APK или ADB, ошибка подключения, отказ установки, ошибки выдачи разрешений, записи настройки и запуска приложения. В сценариях ошибок проверяется остановка перед следующими командами и отсутствие сообщения об успешной установке. Пути содержат пробелы и кириллицу; отдельно проверяется выбор нового APK без удаления приложения или использования v3.0.

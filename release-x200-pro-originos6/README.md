# Gemini by kaiser — релиз для X200 Pro / OriginOS 6

Версия **3.1-x200pro-originos6** для **Vivo X200 Pro с OriginOS 6** и компьютера с Windows. В этой папке уже есть APK, установщик и ADB с нужными DLL. Остальные папки репозитория для установки не нужны.

Это отдельный вариант. Исходная v3.0, проверявшаяся на X500 Ultra / OriginOS 7 по информации владельца, сохранена без изменений. Для X500 Ultra используйте исходную версию.

## Как установить

1. Распакуйте ZIP целиком. Запускать `.bat` прямо из окна архива не нужно: APK и папка `platform-tools` должны находиться рядом с ним
2. На телефоне должны быть установлены и работать **Google** и **Gemini**. Этот комплект устанавливает утилиту для вызова Gemini; сами приложения Google в него не входят
3. Включите **Отладку по USB** в настройках разработчика телефона. Подключите к компьютеру только один телефон и подтвердите окно **Разрешить отладку по USB**
4. Разблокируйте экран и оставьте его включённым до завершения установки. Используйте основной профиль Android, user 0
5. Запустите **`Install_Gemini_X200_Pro_OriginOS6.bat`**. Проверьте показанные модель и сборку, затем нажмите **Y**, если это ваш X200 Pro / OriginOS 6. **N** отменяет установку
6. Дождитесь сообщения **APK X200 PRO / ORIGINOS 6 УСТАНОВЛЕН**. Скрипт установит APK, выдаст разрешения, настроит вызов ассистента и откроет утилиту
7. В Gemini откройте **Профиль → Настройки → Управление устройствами → Gemini на заблокированном экране** и разрешите использование без разблокировки
8. В утилите нажмите **OriginOS: Google на экране блокировки** и включите **Display on lock screen**. Через соседнюю кнопку разрешите это же для утилиты, а также **Background pop-ups** и **Autostart**
9. Если служба специальных возможностей выключена, откройте информацию об утилите, разрешите ограниченные настройки через меню с тремя точками и включите службу **Gemini & Circle to Search — X200 Pro / OS 6**
10. Для вызова голосом отдельно включите **Hi, Jovi** в настройках голосового пробуждения

После установки заблокируйте телефон, удержите питание около половины секунды и задайте простой вопрос. Затем закройте Gemini, подождите больше пяти секунд и отдельно проверьте фразу **Hi, Jovi**. Ответ должен озвучиваться без ручного нажатия «Слушать».

## Если установка остановилась

- **Телефон не найден / unauthorized:** проверьте кабель, отладку по USB и подтверждение на телефоне. После запуска ADB скрипт делает до десяти проверок подключения
- **INSTALL_FAILED_ABORTED / User rejected permissions:** разблокируйте телефон, подтвердите установку, если появился запрос, и повторите запуск
- **INSTALL_FAILED_UPDATE_INCOMPATIBLE:** подпись установленной утилиты отличается. Для перехода с исходной v3.0 удалите только прежнюю утилиту **Gemini by kaiser** вручную, затем повторите установку. Разрешения утилиты потребуется выдать заново. Google и Gemini удалять не нужно
- **Jovi закрывается, а Gemini не появляется:** проверьте разрешения OriginOS из шага 8
- **После очистки памяти вызов перестал работать:** очистка может выгрузить процессы Google. Откройте Google / Gemini и утилиту заново, затем повторите вызов и проверьте службу специальных возможностей

Скрипт останавливается при ошибке и не удаляет приложения автоматически. Уже применённые системные настройки автоматически не откатываются. При установке поверх этого же варианта с той же подписью предварительное удаление не требуется.

## Возврат к исходной версии

Для возврата удалите вариант X200 Pro и установите исходную v3.0 по [инструкции проекта](https://github.com/kaiser10669-svg/gemini-origin-os#-установка). Из-за разных подписей две версии одновременно не устанавливаются.

Удаление утилиты само по себе не возвращает системные настройки. Для возврата голоса Jovi выберите **BlueAI → BlueLM Copilot → Announcement mode → Automatic announcement**. При необходимости восстановите назначение кнопки питания и ассистента в настройках телефона после удаления утилиты.
